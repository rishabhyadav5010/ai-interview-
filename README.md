# 🤖 PrepAI - AI Mock Interview Platform

An intelligent, interactive AI-powered mock interview platform for technical, behavioral, and role-specific interview preparation with real-time feedback, speech recognition, and instant scorecards.

---

## 👥 Team & Collaboration
This repository is configured for team collaboration.

### 📌 For Partner / Collaborator:
1. **Clone the repository:**
   ```bash
   git clone https://github.com/rishabhyadav5010/ai-interview-.git
   cd ai-interview-
   ```
2. **Install dependencies:**
   ```bash
   npm install
   ```
3. **Run local development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🛠️ Tech Stack
- **Framework:** Next.js (App Router, React 19, TypeScript)
- **Styling:** Tailwind CSS 4
- **Icons:** Lucide React
- **Voice / Speech:** Web Speech API & Web Audio
- **AI Engine:** Google Gemini AI API
